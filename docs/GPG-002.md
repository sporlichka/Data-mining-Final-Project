- **Link:** https://www.kaggle.com/datasets/fedesoriano/gender-pay-gap-dataset
- **File:** `CurrentPopulationSurvey.csv` (~280 MB, not committed to the repo — listed
  in `.gitignore`; download it from the Kaggle link above)

## Size

| Metric | Value |
|---|---|
| Records | 344,287 |
| Features (columns) | 234 |
| Time span | 1981–2013 (survey years; most-represented years: 2007, 2009, 2011, 2013, 1990, 1981, 1999) |
| Population | Employed persons only (`empstat` = 10 Employed or 12; `labforce` = 2, in the labor force). Unemployed / not-in-labor-force records are excluded. |

## Target Variable

Candidates for the regression target:

- **`incwage`** — annual wage/salary income. Primary candidate.
- **`realhrwage`** — inflation-adjusted real hourly wage. Economically preferable
  because it removes the confound of men and women working different numbers of
  hours/weeks.

Modeling will most likely use **`log(realhrwage)`**, standard practice in wage-gap
analysis (Mincer wage equation), because it:
- reduces the effect of strong right-skew and outliers;
- lets model coefficients be interpreted as approximate percentage wage
  differences.

Key predictor of interest for RQ2/RQ3: **`sex`** (1 = male, 2 = female) /
**`female`** (0/1 dummy).

## Feature Types

| Group | Examples | Type |
|---|---|---|
| IDs / sample weight | `year`, `serial`, `wtsupp` | numeric, technical (not model features) |
| Demographics | `age`, `sex`, `race`, `marst`, `hispan`, `nativity`, `citizen` | categorical / numeric |
| Education | `educ99`, `ba`, `adv` | categorical / binary |
| Employment | `empstat`, `classwkr`, `wkswork1`, `uhrswork`, `union` | categorical / numeric |
| Experience | `potexp`, `potexp2` | numeric (derived from age and education) |
| Occupation / Industry | `occ1990`, `ind1990`, `adj_occ2name`, ~40 binary occupation/industry dummies (`manager`, `sales`, `healthcare`, …) | binary / categorical |
| Geography | `region`, `statefip`, `northeast`, `south`, `west`, … | categorical / binary |
| Income | `incwage`, `incbus`, `incfarm`, `hrwage`, `realhrwage`, `lnrwg` | numeric (continuous) |

Overall, the dataset mixes continuous numeric variables (age, income, experience,
hours worked) with a large number of categorical/binary variables (socio-demographic
and occupation/industry dummies).

## Missing Values

Missingness is concentrated in a handful of columns (the remaining ~210 columns have
no missing values):

| Feature | Missing % | Note |
|---|---|---|
| `citizen` | 87.06% | only collected in a subset of survey years |
| `nativity` | 25.51% | same — not asked in every CPS wave |
| `educ99` | 25.39% | education coding, absent in some years |
| `union` | 12.31% | union-membership question not always asked |
| `hispan` | 0.41% | minimal missingness |
| `age`, `sex`, `race`, `marst`, `empstat`, `incwage`, `hrwage`, `realhrwage` | 0% | fully populated |

Missing values are encoded as the literal string `"NA"` in the CSV and require
explicit handling at preprocessing time (GPG-003): either imputation with a
missingness indicator, or a justified drop if missingness correlates systematically
with survey year.

## Class Distribution / Key Variable Breakdown

- **Sex:** male — 51.09% (175,911), female — 48.91% (168,376) — a balanced sample.
- **Raw gender wage gap** (no controls):
  - mean `incwage`: \$47,730 (men) vs \$31,437 (women) → women earn **~34.1% less**;
  - median `incwage`: \$35,000 vs \$24,000 → **~31.4% less**;
  - median `realhrwage`: \$20.45 vs \$15.14 — the gap persists on an hourly basis,
    i.e. it is not purely a function of women working fewer hours.
- **Race:** White — 69.8%, Black — 14.3%, other groups — 6.3–9.6% (strong
  imbalance, relevant for interpretation).
- **Education (`educ99`), top categories:** code `10` (20.7%), `15` (16.9%), `11`
  (13.0%), `16` (6.9%) — codes correspond to levels from "some college" to "master's
  degree" under IPUMS CPS coding.
- **Occupation (`adj_occ2name`), top categories:** Office and Admin Support (14.7%),
  Managers (10.4%), Construction/Extraction/Installation (8.9%), Production (8.6%) —
  strong imbalance and visible occupational gender segregation, one of the factors to
  dig into during EDA/feature engineering.
- `realhrwage` / `incwage` contain outliers (CPS top-coded wage values — an upper
  measurement bound), requiring dedicated outlier analysis during preprocessing.
